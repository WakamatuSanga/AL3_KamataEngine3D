# 11月分進捗
## 操作方法
WASDで移動
スペースキーで射撃  
## 今月の成果一覧
- プレイヤーの移動と連射を追加して敵を新しく3体追加した。  
  - プレイヤーに関しては簡単だったがエネミーの処理を少し雑に書いてしまったので12月は敵の処理を綺麗にします。
- 離脱、追従、ロックオンを追加した。天球を追加した。  
  - クラスで作ったが処理がバラバラになっているのでそれをまとめようと思います。
- 流れる地面(海)を追加した。  
  - モデルがめんどくさかったが処理は簡単でした。
- 敵を倒しても敵の弾はカウントで消えるようにした。  
  - ここの処理で2時間エラー直しした。
- 曲線補間でレールカメラの移動を追加した  
  - レールカメラが思ったよりも癖が強くて時間がかかった。
- プレイヤーがカメラの向きによって向くようにした  
  - いまだに自分が思った動きをしていないためそこを直したいです。
## その他
10月で追加していた移動や小さいギミックを追加し、プレイヤー周りとエネミー関連を作ったが自分が思い描いた動きをしていないため12月で色々プログラムを軽くして便利にしていきます。
